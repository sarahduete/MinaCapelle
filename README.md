# ☕ Mina Capelle Café & Cia
Site institucional para cafeteria

O Mina Capelle Café & Cia é um projeto desenvolvido com o objetivo de apresentar a cafeteria, seus produtos e sua identidade por meio de uma página institucional.

🔗 **[Acessar o site](https://minacapelle.lovable.app/)**

## 📖 Sobre o projeto

O projeto surgiu da ideia de criar uma presença digital para a Mina Capelle Café & Cia, reunindo informações sobre a cafeteria e facilitando o acesso dos clientes aos seus produtos e canais de contato.

A proposta foi desenvolver um site que transmitisse a personalidade da marca e apresentasse o estabelecimento de forma organizada e acolhedora.

## 💻 Como foi desenvolvido

O desenvolvimento começou com a análise da identidade da marca e o planejamento da estrutura do site.

A proposta visual foi pensada para combinar com o segmento de cafeteria, valorizando as imagens dos produtos e criando uma apresentação agradável.

Em seguida, trabalhei na estrutura utilizando HTML, organizando as seções de apresentação, sobre a cafeteria, produtos, cardápio e contato.

Na parte visual, utilizei CSS para definir a composição das páginas, trabalhar a tipografia, as cores e os espaçamentos.

Também trabalhei na organização das informações para que os visitantes pudessem conhecer melhor a cafeteria e encontrar facilmente seus canais de atendimento.

## ⚙️ Funcionalidades

- Apresentação da cafeteria.
- Seção sobre a marca.
- Destaque para produtos.
- Apresentação do cardápio.
- Galeria de imagens.
- Informações de localização.
- Links para redes sociais.
- Contato.
- Layout responsivo.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
